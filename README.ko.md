# 로드스터 몬테카를로 성능 시뮬레이션

[Read in English →](README.md)

고성능 전기차("로드스터" 스타일)의 직진 가속을 MATLAB + Simulink로 모델링하고, 타이어 접지력·공기밀도/항력·적재중량·모터 출력 저하·도로 경사 같은 조건을 매번 무작위로 바꿔가며 수백 번 돌려서 **성능 분포**를 뽑는 프로젝트입니다 — 0-100km/h 숫자 하나가 아니라, 실제로 여러 번 탔을 때 나올 법한 편차를 보여줍니다.

## 현재 상태: 빌드·실행 완료 (MATLAB R2024b)

`build_roadster_model.m`은 코드 수정 없이 첫 실행에서 `RoadsterLongitudinal.slx`를 빌드했고, 20회 검증도 통과했습니다(전 trial 유한값, 0-100 km/h가 타당 범위). **500회 본 실행**(`rng(2024)`, 순차 실행, NaN 없음) 결과:

| 지표 | 평균 | 표준편차 | 5th 백분위 | 95th 백분위 |
|---|---|---|---|---|
| 0-100 km/h (s) | 3.10 | 0.22 | 2.80 | 3.49 |
| 1/4마일 (s) | 10.67 | 0.20 | 10.36 | 11.03 |
| 트랩 속도 (km/h) | 221.5 | 3.4 | 216.1 | 226.9 |
| 12초 시점 속도 (km/h) | 234.4 | 5.1 | 226.1 | 242.8 |

기준 파라미터(`default_vehicle_params.m`, 초안 값 그대로이며 재튜닝하지 않음): 질량 1750 kg, mu 0.95, `k_aero` 0.343, `T_peak` 8250 N·m, `P_peak` 400 kW(휠 기준). 대시보드: `monte_carlo_dashboard.png`.

검증에서 확인된 한계:
- `T_peak`는 제한 요인이 아닙니다. 8250/0.33 ≈ 25 kN이 견인 한계 mu·m·g ≈ 16.3 kN보다 커서 발진은 mu가 결정하고, `T_peak`의 분산은 결과에 영향이 없습니다.
- 휠 출력을 구동계 손실·관성·열 제한 없이 400 kW로 두고 t=0부터 최대 가속하므로, 트랩 속도(~221 km/h)는 낙관적입니다.
- `vMax_kmh`는 진짜 최고속도가 아니라 12초 정지 시점의 속도입니다.
- 결과는 단순화한 점질량 모델 기준이며 실제 차량 모델로 검증된 것이 아닙니다.

## 이게 뭐고, 뭐가 아닌지

- **맞는 것**: 단순화된 단일 트랙(점질량, 직진) 종방향 차량 모델 — 트랙션 한계 출발 → 정토크/정출력 모터 특성 → 공기저항·구름저항·경사저항으로 감속되는 구조입니다.
- **아닌 것**: 특정 실제 차량의 구동계를 그대로 재현한 게 아닙니다. AWD 토크 벡터링, 서스펜션/하중 이동, 시간에 따른 배터리 잔량/열 이력, 횡방향 거동 전부 없습니다. 제조사가 발표한 숫자를 정확히 맞추려는 게 아니라, 조건에 따라 성능이 *어떻게 달라지는지* 살펴보기 위한 단순 모델입니다.

## 구조

```
matlab/
├── default_vehicle_params.m   # 기준값 + 몬테카를로 분포 (차량을 바꾸려면 이 파일만 수정)
├── build_roadster_model.m     # RoadsterLongitudinal.slx 생성·저장 (한 번만, 또는 다이어그램을 바꿀 때마다 실행)
├── run_monte_carlo.m          # N번 샘플링·시뮬레이션·결과 저장·대시보드 실행까지 한 번에
├── analyze_results.m          # 시행별 0-100km/h 시간, 1/4마일 시간·트랩 스피드 추출
└── plot_dashboard.m           # 다크 테마 요약 대시보드(히스토그램·민감도 산점도·백분위수)
```

**모델**: `RoadsterLongitudinal.slx`는 오래전부터 안정적인 기본 Simulink 블록(Integrator, Gain, Sum, Divide, MinMax, Math Function, Constant, To Workspace)만으로 구성돼서, 기본 MATLAB + Simulink 외에 추가 툴박스가 필요 없습니다. 몬테카를로 시행마다 바뀌는 값(질량, 트랙션 한계, 항력, 구름·경사 저항, 모터 토크/출력 한계)은 전부 블록 다이얼로그에 "이름"으로만 들어가 있고, 매 시행마다 `Simulink.SimulationInput.setVariable`로 값을 넣어줍니다 — 시행 사이에 다이어그램을 다시 만들 필요가 없습니다.

**몬테카를로**: 매 시행마다 독립적으로(절단정규분포) 아래 값을 뽑습니다.
- 차량 질량(탑승자/적재 하중)
- 타이어-노면 마찰계수(도로/타이어 상태)
- 공기저항 계수(공기밀도 + Cd·전면적의 작은 변동)
- 구름저항 계수
- 도로 경사
- 모터 최대 토크·최대 출력(배터리/열 저하)

그다음 0~12초를 시뮬레이션해서 100km/h 도달 시간과 1/4마일(402.336m) 통과 시간·트랩 스피드를 뽑아냅니다.

**병렬화**: Parallel Computing Toolbox가 있으면 `run_monte_carlo.m`이 자동으로 `parsim`을 쓰고, 없으면 평범한 순차 반복으로 대체됩니다(느리지만 추가로 필요한 게 없음).

## 실행 방법

```matlab
cd matlab
results = run_monte_carlo();        % 기본 500회
% results = run_monte_carlo(2000);  % 더 많이 돌려서 분포를 매끄럽게
```

모델이 없으면 자동으로 만들고, 몬테카를로 배치를 돌리고, `monte_carlo_results.mat`에 저장한 뒤 대시보드를 자동으로 띄웁니다. `results`는 시행마다 한 줄씩인 테이블로, 추출된 지표(`t_0_100_kmh_s`, `t_quarterMile_s`, `trapSpeed_kmh`, `vMax_kmh`)와 그 시행에서 뽑힌 조건값(`mass`, `mu`, `k_aero`, `Crr`, `gradeDeg`, `T_peak`, `P_peak`)이 함께 들어 있어서, 기본 대시보드 말고도 원하는 대로 민감도를 잘라보고 그릴 수 있습니다.

차량을 바꾸고 싶으면(더 가볍게/무겁게, 타이어를 더 잘 붙게, 출력을 더 올리거나 내리거나, 분포 폭을 좁히거나 넓히거나) `default_vehicle_params.m`만 고치면 됩니다.

## 실제로 돌려본 뒤 손볼 것들

실제로 실행할 수 있게 되면 확인·조정해볼 만한 것들입니다.

- `default_vehicle_params.m`의 기준값들은 손계산으로 고른 뒤 실제 20회·500회 실행으로 확인했습니다(현재 상태 참고). `T_peak`는 제한 요인이 아니라서, 분산이 결과에 반영되길 원하면 ~5000-6000 N·m로 낮출 수 있습니다.
- `p.sim.stopTime`(12초)은 기준값 기준으로 0-100km/h와 1/4마일을 넉넉히 커버하도록 잡았습니다 — 결과 테이블에 `NaN`이 많이 나온다면, 그 시행의 차량이 시뮬레이션 구간 안에 못 끝낸 것입니다(진짜 "느린 이상치"로 남겨둘지, 아니면 stopTime을 늘릴지 판단하면 됩니다).
- 히스토그램이 매끄럽게 나오려면 `N=500` 정도가 적당하지만, 모델을 디버깅하는 동안에는 `N`을 50 정도로 낮춰서 빠르게 반복하는 걸 추천합니다.
